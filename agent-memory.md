# Agent Memory

- harness/run.js: `shapeValue` mode-driven, validate/normalize only, no payload fabrication.
- script-item/webhook: accept object or stringified JSON; plain string passed through if parse fails.
- preprocessor: return `params.value` if present, else return `params` as-is.
- script.js: example is script-item oriented (url, expectedStatusCode, searchText); not a contract for other modes.
- Adapting to preprocessor/webhook: adjust input/output contract explicitly in that script.
- script.zabbix.js: auto-generated by `npm run build:zabbix` — never edit directly; edit script.js.
- params.json: developer-defined per project; example structure not a contract.
- todo.md: agent-developer handoff file. Developer writes plan; agent appends `[ HANDOFF ]` items needing manual action.

# Agent instructions baseline

- Read `README.md` and `agent-memory.md` before starting.
- Help developer use VS Code tasks and debug options.
- script.js must be Zabbix Duktape + ES5 compatible.
- Lint via VS Code task or `npm run lint`.
- Flag and correct ES6+ syntax in script.js.
- Save tokens: no glazing, no personality, plain language, brutal honesty, sparse decorations, abbreviate (keep technical terms).
- Update `agent-memory.md` with decisions, patterns, or constraints found during session.
